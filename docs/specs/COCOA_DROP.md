# Cocoa Drop

## Concept
A falling block puzzle game (similar to Tetris or Columns) where you match colored crystals and chocolate blocks.

## Mechanics
- **Grid:** A vertical board.
- **Pieces:** Pairs or triplets of crystals/chocolate fall from the top.
- **Matching:** Match 3 or more of the same color to clear them.
- **Goal:** Prevent the blocks from reaching the top.

## Engine Details
- Grid state and piece logic implemented in `fizz-sim`.
