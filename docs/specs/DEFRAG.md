# Defrag the Mainframe

## Concept
A nostalgic retro DOS action-puzzle inspired by MS-DOS 6.22 `DEFRAG.EXE` and Norton SpeedDisk. A mischievous Cluster-Worm is scrambling Lieutenant Fizz's field computer memory banks. Players navigate the magnetic Read/Write Head, sorting fragmented clusters into contiguous rows to optimize cylinders, zap the worm, and achieve 100% disk optimization.

## Mechanics
- **Cluster Matrix:** A $16 \times 8$ sector map with CP437 glyphs:
  - System Clusters: Immovable protected memory (`█`).
  - Data Clusters: Colour-coded blocks (Cyan, Yellow, Red, Green).
  - Free Sectors: Dithered empty blocks (`░`).
  - Bad Sectors: Corrupted clusters (`X`) generated by the worm.
- **Read/Write Head:**
  - Pilot the head cursor using `Arrows` or `WASD`.
  - Press `Space` to read a cluster into the head buffer, or write the buffered cluster into the current slot.
- **Defragmentation & Scoring:**
  - Aligning 4 or more contiguous identical coloured clusters in a row or column optimizes the cylinder.
  - Cleared sectors advance the optimization progress meter toward $100\%$ and repel the Cluster-Worm backwards.
- **Cluster-Worm Hazard:**
  - A digital worm crawls along memory tracks, corrupting empty sectors into bad sectors and scrambling coloured data.
- **Time Attack:** 75-second shift to complete disk optimization.

## Controls
- `Arrows` / `WASD`: Move Read/Write head cursor
- `Space`: Swap / write cluster block
- `P`: Pause defragmentation
- `Esc`: Return to Hub
