# Gloop Slugger

## Concept
A Whack-a-Mole clone where Gloop slugs pop out of craters in the Cocoa Fields.

## Mechanics
- **Grid:** A 3x3 grid of craters.
- **Action:** Quickly target and blast a Gloop slug when it appears before it retreats.
- **Hazards:** Sometimes a Zarg phantom pops out; hitting it costs points or time.

## Engine Details
- Use `fizz-sim` for grid logic and timing.
